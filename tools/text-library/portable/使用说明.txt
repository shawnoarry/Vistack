拾句 · 本地文字库（Windows x64 空库便携版）

开始使用
1. 将压缩包完整解压到可写的文件夹，不要直接在压缩包里运行。
2. 双击“启动拾句.cmd”。无需安装 Node.js 或其他开发环境。
3. 浏览器会打开本机拾句页面；使用期间保留启动窗口。
4. 此包不包含任何个人文案、分类、备份或旧文档。可以直接收录文字。

数据在哪里
首次保存后，文字库保存为启动器旁的 text-library.json。
每次保存前保留上一版 text-library.json.bak。
浏览器清缓存不会删除此文件，但磁盘删除或损坏会影响数据。
请定期在“数据与备份”中导出完整 JSON，另存到其他磁盘。
以后更新只替换“拾句”程序子文件夹，保留启动器旁的 JSON 和备份文件。

收录与分类
单条直接收录；批量可粘贴文字或导入 UTF-8 TXT、本工具 JSON。
TXT 可选空行分条或每行一条，先检查预览，再确认导入。
明确的署名会自动拆分到作者与作品字段，未标明的未知人名不强行猜测。
可关闭“识别作者与作品”；已拆分的原始输入保留在“收录原文”中。
不支持直接导入 DOC / DOCX。
分类可在“我的分类”旁管理，名称可修改。
删除分类只将文案移至未归类，不删除文案。
JSON 导入会新增不同名的分类，同名合并，不覆盖本地已有分类和重复正文。
每个人的数据独立保存，不会自动同步。

复制与导出
“复制文案”和“复制作者及出处”分别对应正文和署名，不复制署名前的破折号。
勾选多条可导出 Markdown、Word DOCX 或 TXT；也可导出当前筛选结果。
完整 JSON 备份包含全部文字、分类、备注、状态历史及原文记录。
分享 JSON 前请确认分享范围；只分享部分文字可使用勾选导出。

图片识字与配色
“图片识字”支持简体中文及英文，在本机完成，不上传图片。
检查并修改识别结果后再收录，尤其注意人名、作品名、生僻字。
宣纸（暖纸白与墨绿）、海盐（浅灰绿与暖白）、胭脂（藕粉与暖白）三种整页配色可在左下角圆点切换。

遇到问题
若提示端口 4178 被其他程序占用，先关闭冲突程序，再启动。
无法读取数据时，不要删除 JSON 或反复覆盖；保留原文件后从备份恢复。
整库恢复与导入合并不同：需先关闭服务，保留当前库，再替换为完整备份。

再次分享空库版
直接转发原始空库压缩包即可。
不要把自己使用后的整个目录直接发出，里面可能已有个人 JSON 数据。
不要只发送快捷方式；对方需要完整程序目录和启动器。
