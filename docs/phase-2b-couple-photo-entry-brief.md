# 阶段 2B：合影助手图标入口

状态：已实施并验证

更新：2026-07-13

适用范围：只调整创作台合影助手的入口和展开方式

## 1. 现在是什么样子

合影助手常驻在创作台左侧“参考图定义”下方。无论是否有两张人物参考图，页面都会显示：

- 合影助手标题和当前状态。
- “启用合影提示增强”开关。
- 合影动作和场景关系两个选择框。
- 补充提示词输入框。
- 启用后的最终合影提示词预览。

没有满足条件时，这些控件全部不可用，但仍占据左侧较大空间。PC 端参考图是高频区域，合影助手却是低频能力，因此两者长期放在同一层级并不匹配实际使用。

当前底部提示词栏已经有一组紧凑图标：撤销、清空、词组、模板、保存模板、AI 优化和翻译。合影助手同样属于“给最终提示词增加内容”的辅助能力，放在这组工具附近更容易理解。

## 2. 推荐改成什么样子

### PC 端

```text
底栏工具： [撤销] [清空] [词组] [模板] [合影] [保存模板] [AI 优化] [翻译]
                                            ↑
                                    点击后向上展开

                         ┌ 合影助手                         [关闭] ┐
                         │ 状态：需要 2 张以上人物参考图            │
                         │ [启用合影提示增强]                       │
                         │ [合影动作] [场景关系]                    │
                         │ [补充提示词                              ]│
                         │ 启用后显示最终拼接内容                    │
                         └──────────────────────────────────────────┘
```

- 从左侧参考图区域移除常驻合影表单以及上方分隔线。
- 在底栏“模板”图标之后增加一个双人轮廓的合影助手图标。
- 点击图标后，在固定底栏上方向上展开一个约 440px 宽的小面板。
- 面板作为临时浮层覆盖内容，不撑高固定底栏，也不改变提示词输入框和生成按钮位置。
- 点击同一图标、面板关闭按钮、面板外区域或按 `Esc` 均可关闭；关闭面板不会关闭已经启用的合影增强。

推荐把图标放在“模板”之后，原因是词组、模板和合影助手都属于提示词内容来源；“保存模板”、AI 优化和翻译仍位于其后，现有工具顺序只插入一个入口，不整体重排。

### 手机端

- 底栏和现有图标顺序不做其他调整，合影图标随工具组自然换行。
- 点击后使用接近全宽的底部抽屉，避免窄屏弹层横向溢出。
- 抽屉内部可以滚动，页面本身不发生横向滚动。
- 这只是同一入口的响应式呈现，不重排手机端创作台其他内容。

## 3. 图标和面板状态

### 条件不足

条件：少于两张被标记为“人物/角色”的参考图。

- 图标保持可点击，但使用较安静的颜色。
- 悬停提示：`合影助手（需至少 2 张人物参考图）`。
- 点击后面板显示：`添加至少 2 张人物参考图后可启用。`
- 动作、关系、补充内容和启用开关保持不可用。

推荐不把图标完全禁用。一个没有文字的灰色图标无法在手机端解释不可用原因；允许打开面板可以让用户看清条件，同时不会误触发功能。

### 条件满足但未启用

- 图标使用普通可用状态。
- 悬停提示：`打开合影助手`。
- 面板内控件可编辑，但必须由用户主动打开“启用合影提示增强”，不自动启用。

### 已启用

- 图标使用与现有已选模板一致的强调边框和文字色，不增加醒目徽章。
- 悬停提示：`合影助手已启用`。
- 关闭面板后强调状态继续保留，让用户知道下一次生成会拼入合影提示词。
- 当人物参考条件不再满足时，合影内容不再拼入请求，图标恢复“条件不足”状态。

### 面板正在打开

- 使用轻量背景变化表达“面板已打开”。
- 打开状态和“功能已启用”是两个不同概念，不用同一套强强调样式代替。
- 图标提供可访问名称“合影助手”，并通过展开状态让键盘和辅助技术能够识别面板是否打开。

## 4. 保留的原有能力

- “启用合影提示增强”开关。
- 所有合影动作和场景关系选项。
- 补充提示词输入框。
- 启用后的最终合影提示词预览。
- 角色映射、防混脸、身份区分和统一光线/透视等现有提示词拼接规则。
- 人物参考图数量判断和不满足条件时不拼入提示词的保护。

入口移动后，相同参考图、相同选项和相同补充内容必须产生与现在完全相同的最终合影提示词。

## 5. 备选方案

### 方案 A：底栏图标 + PC 向上浮层 / 手机底部抽屉（推荐）

优点：符合用户提出的图标入口；PC 使用路径短；不会撑高固定底栏；手机也能完整显示控件。

风险：浮层会暂时覆盖部分结果内容，需要稳定的关闭方式和最大高度。

### 方案 B：底栏图标 + 居中弹窗

优点：实现和空间管理简单，所有尺寸都能容纳。

缺点：操作一个提示词辅助功能时会遮住并阻断整个创作台，层级偏重。

### 方案 C：左侧折叠标题

优点：代码变化最小，仍靠近参考图。

缺点：即使折叠后仍占据左侧主流程位置，也不符合用户希望放入简略图标入口的方向。

## 6. 保持不变

- PC 端固定底部提示词栏的位置、高度和持续可见行为。
- 词组、模板、保存模板、AI 优化和翻译图标及其功能。
- 参考图上传、用途标记、名称、排序和数量限制。
- 图生图/文生图动态按钮。
- 提示词预览、结果区、近期资产、画布和工具箱。
- API 配置、模型参数、供应商路由和请求格式。
- 历史图片、提示词、API 预设和本地存储结构。
- 合影助手现有设置的内存行为；本阶段不增加跨浏览器重开保存。

## 7. 风险与控制

- 新图标可能让底栏工具在较窄 PC 宽度换行。实施时必须检查 1440px、1280px 和 1024px，不能让底栏高度意外增加或遮住生成按钮。
- 浮层可能超出窗口顶部。设置最大高度和内部滚动，不让整个页面横向溢出。
- 面板关闭后，已启用状态可能被用户遗忘。图标必须保留安静但明确的已启用状态。
- “条件不足”和“功能未启用”不能混为一类，面板要分别说明。
- 移动表单时不能重写合影提示词生成逻辑；相同输入的最终文本必须保持一致。
- 不新增数据迁移，不修改历史和 API 预设。

## 8. 验收标准

- 左侧参考图区域不再常驻显示合影助手完整表单。
- 底栏模板图标之后出现一个尺寸、线宽和交互状态与现有工具一致的合影助手图标。
- PC 端点击图标后面板在固定底栏上方展开，底栏高度、提示词输入框和生成按钮位置不发生变化。
- 少于两张人物参考图时，图标可打开说明面板，且用户能明确看到需要补充什么。
- 满足条件后可使用全部原有选项；只有用户主动启用后才拼入最终提示词。
- 面板关闭后，已启用状态仍能从图标识别；再次打开时当前选项和补充内容仍在。
- 相同输入在调整前后产生完全相同的合影提示词和生成请求。
- 点击图标、关闭按钮、外部区域和按 `Esc` 都能关闭面板，键盘焦点可正常返回图标。
- 1440×900、1280×800 和 1024×768 PC 视口中，固定底栏持续可见且没有新增换行、遮挡或横向溢出。
- 390×844 手机视口中，底部抽屉可完整操作且页面无横向溢出。
- `npm run check` 全部通过，浏览器控制台无新增警告或错误。

## 9. 获得确认后的实施顺序

1. 先增加合影状态和提示词不变的行为测试。
2. 增加面板开关状态，把现有表单原样移动到底栏浮层中。
3. 在模板图标之后加入合影助手图标及其条件不足、可用、已启用和展开状态。
4. 移除左侧原合影表单，不调整参考图其他内容。
5. 增加 PC 浮层和手机底部抽屉的响应式行为、键盘关闭和焦点返回。
6. 运行完整检查与桌面/手机浏览器验证，更新记录并建立独立检查点。

## 10. 实施结果

- 用户确认了三项推荐决定：图标放在模板之后、PC 使用向上浮层/手机使用底部抽屉、条件不足时仍可点击查看原因。
- 左侧常驻合影表单已移除，参考图上传与核对区域未改变。
- 底栏模板图标之后已加入合影助手图标，使用标准双人轮廓；关闭按钮同样使用标准图标。
- 条件不足、可用、已启用和面板展开状态均有独立文案与视觉反馈。
- PC 面板宽 440px，向固定底栏上方展开，不增加底栏高度。
- 手机面板通过页面根层渲染为底部抽屉，避免底栏背景模糊形成错误定位参照。
- 点击同一图标、关闭按钮、外部区域和按 `Esc` 都能关闭，关闭按钮和 `Esc` 会把焦点返回入口。
- 词组面板与合影面板不会同时覆盖页面。
- 合影提示词拼接已提取为纯函数并用完整文本测试锁定；生成请求没有改变。

验证结果：

- `npm run check` 通过：7 个测试文件、40 项测试、类型检查和生产构建均成功。
- 1440×900、1280×800 和 1024×768 下，固定底栏高度均保持 241px，图标完整可见且页面无横向溢出。
- 1440×900 下，面板为 440px 宽并位于底栏上方；底栏位置与高度不变。
- 390×844 下，抽屉底部精确贴合视口底部，可内部滚动且无横向溢出。
- 全新桌面/手机页面从加载到打开面板均无控制台警告或错误。
