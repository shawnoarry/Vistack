# GPT Image2 提示词价值验证包

状态：六场景验证材料已准备，G3-lite 配方已接入现有模板；真实 A/B 尚未执行

准备时间：2026-08-15

参考基线：[wuyoscar/GPT-Image2-Skill](https://github.com/wuyoscar/GPT-Image2-Skill) commit `068dd9e24aadc8731e46f38548ca4dcd94515d35`

## 验证目的

这个验证包只回答一个问题：外部项目总结的提示词结构，是否能改善 Vistack 当前最常用的改图任务。

它不测试新模型、新参数或新接口，也不证明 GPT Image 2 一定优于其他模型。六组提示词均为 Vistack 场景重新编写，没有复制上游图库中带外部作者来源的 Prompt，也没有打包任何上游示例图片。

## 安全边界

- 不修改 API Key、接口地址、模型、代理或连接预设。
- 不修改请求 payload、供应商路由、尺寸规则或批量逻辑。
- 本验证文档本身不写入用户模板、Prompt Pool 或本地存储；后续获批的 G3-lite 仅新增六条内置纯文本模板。
- 不自动调用任何 API，也不会产生费用。
- 不要求使用私人或敏感照片；人工测试时由使用者自行选择合适素材。
- 实际点击生成属于普通 Vistack 生成，会按当前账号计费并进入正常历史；本验证包本身不会执行该步骤。

## A/B 测试方法

每个场景都包含：

- A 组：接近日常输入习惯的简短提示词。
- B 组：加入明确目标、参考职责、不变量和针对性限制的结构化提示词。

测试时保持以下条件完全相同：

1. 使用同一组参考图，顺序不变。
2. 使用同一 API 连接、模型、比例、分辨率和生成数量。
3. A、B 都直接放进主提示词框，不使用提示词助手再次优化。
4. 首轮每组只生成 1 张，避免不必要费用。
5. 当 A、B 总分只差 0 到 1 分时，再各生成 1 张复核；否则不重复。
6. 不在记录中保存 API Key、代理令牌或包含敏感查询参数的完整接口地址。

## 统一评分

每项 0 到 2 分，总分 10 分。

| 项目 | 0 分 | 1 分 | 2 分 |
| --- | --- | --- | --- |
| 目标修改 | 基本没有完成 | 完成一部分 | 修改准确完整 |
| 不变量保持 | 重要内容明显漂移 | 有轻微漂移 | 应保留内容稳定 |
| 参考职责 | 混用或忽略参考图 | 大体正确 | 每张图职责清楚 |
| 画面自然度 | 拼贴、变形或违和 | 可用但有瑕疵 | 融合自然可信 |
| 错误控制 | 多余人物、乱码或严重结构错误 | 有一处明显问题 | 没有明显错误 |

## 场景 1：保持身份，只改变环境与拍摄语境

**验证重点：** 场景和拍摄质感发生变化，但仍然是参考图中的同一个人。

**参考图：** 1 张清晰人物图，标记为“人物/角色”。

**A 组提示词：**

```text
把参考图中的女生改成雨夜首尔街头的真实手机抓拍，保持是同一个人。
```

**B 组提示词：**

```text
编辑目标：把参考图 1 中的人物放到雨夜首尔街头，生成真实手机抓拍照片。

参考职责：参考图 1 只作为人物身份锚点。最终人物必须是参考图中的同一位成年女性，而不是相似人物。

需要改变：环境改为雨后街道、湿润路面、店铺灯光和自然城市夜景；拍摄质感改为手持手机抓拍，带轻微运动感和真实环境光。

必须保持：脸型、五官比例、眼型、鼻唇结构、肤色、年龄感、发型主体特征和自然体型。不要改变人物身份，不要过度磨皮或改成通用偶像脸。

画面要求：人物与环境的光线、透视、色温和边缘自然统一。避免多余人物抢占主体，避免随机文字、水印、脸部漂移和身体变形。
```

**观察点：** 先看脸部身份，再看人物是否像被自然拍摄，而不是贴到新背景上。

## 场景 2：只换服装

**验证重点：** 服装准确替换，同时人物身份、姿态和背景不变。

**参考图：**

- 参考图 1：人物图，标记为“人物/角色”。
- 参考图 2：目标服装图，标记为“服装”。

**A 组提示词：**

```text
让参考图 1 的女生穿上参考图 2 的衣服，其他内容保持不变。
```

**B 组提示词：**

```text
编辑目标：只替换参考图 1 中人物的服装。

参考职责：参考图 1 提供人物身份、脸部、发型、体型、姿态、镜头和背景；参考图 2 只提供服装的版型、颜色、材质、纹理和配饰细节。

需要改变：把参考图 2 的完整服装自然穿到参考图 1 的人物身上，服装应符合原有身体比例和姿态，并呈现合理褶皱、遮挡和受光。

必须保持：参考图 1 的脸、发型、肤色、年龄感、身体比例、手部位置、姿态、构图、镜头、背景和光线。不要换脸，不要改变动作，不要重做背景。

避免：混入参考图 2 的人物身份或背景，避免服装漂浮、肢体穿模、额外配饰、随机文字和水印。
```

**观察点：** 服装来自参考图 2，但人和照片主体结构必须继续来自参考图 1。

## 场景 3：只替换背景

**验证重点：** 背景替换准确，人物和前景边缘稳定。

**参考图：**

- 参考图 1：包含人物的原图，标记为“人物/角色”。
- 参考图 2：咖啡店窗边环境，标记为“背景”。

**A 组提示词：**

```text
把参考图 1 的背景换成参考图 2 的咖啡店，人物保持不变。
```

**B 组提示词：**

```text
编辑目标：只把参考图 1 的背景替换为参考图 2 的咖啡店窗边环境。

参考职责：参考图 1 提供人物、姿态、服装、前景物体、构图和相机位置；参考图 2 只提供空间类型、装修材料、窗景和环境氛围。

需要改变：重建人物身后的环境，使其成为自然的咖啡店窗边座位，并让背景透视、景深、光线方向和色温与人物一致。

必须保持：人物身份、脸、发型、服装、身体比例、姿态、手部位置、前景物体、主体尺寸和原始构图。人物轮廓、头发边缘和半透明细节必须自然。

避免：把参考图 2 中的人或家具复制到前景，避免人物被重新设计、边缘发光、背景拼贴感、随机文字和水印。
```

**观察点：** 人物边缘、发丝、玻璃反光和背景透视是否自然，是本场景的主要差异。

## 场景 4：多参考图按角色合成

**验证重点：** 三张参考图各司其职，不混脸、不串背景、不误用风格。

**参考图：**

- 参考图 1：人物身份，标记为“人物/角色”。
- 参考图 2：服装，标记为“服装”。
- 参考图 3：场景或空间，标记为“背景”。

**A 组提示词：**

```text
让参考图 1 的人物穿参考图 2 的服装，出现在参考图 3 的场景里，生成自然写真。
```

**B 组提示词：**

```text
合成目标：生成一张真实自然的环境写真，人物、服装和背景分别来自不同参考图。

参考图 1：只负责人物身份、脸部结构、发型、肤色、年龄感和自然体型。
参考图 2：只负责服装版型、颜色、材质、纹理和配饰，不采用其中的人物或背景。
参考图 3：只负责场景空间、环境材料、背景陈设和整体光线语境，不采用其中的人物。

组合方式：让参考图 1 的同一人物自然穿着参考图 2 的服装，处于参考图 3 的环境中。统一三者的透视、人物尺度、光线方向、阴影、色温和景深，使画面像一次真实拍摄。

必须保持：人物身份不能与参考图 2 或 3 混合；服装不能被随意改款；背景不能覆盖人物或改变人物姿态。

避免：平均五官、换脸、复制参考图中的其他人物、服装与身体穿模、明显拼贴边缘、随机文字和水印。
```

**观察点：** 分别核对“谁”“穿什么”“在哪里”，三项都正确才算完成。

## 场景 5：视觉遮罩辅助的局部细节修正

**验证重点：** 当前 Vistack 尚未提交原生 alpha mask，本场景只验证现有“底图 + 黑白视觉遮罩”的提示约束效果。

**参考图：**

- 参考图 1：原始底图。
- 参考图 2：工具箱导出的黑白遮罩，白色区域覆盖需要修正的右手，黑色区域表示尽量保持。

**A 组提示词：**

```text
修正人物右手的手指结构，其他地方不要改。
```

**B 组提示词：**

```text
局部编辑目标：只修正人物右手的手指结构和自然握持关系。

参考职责：参考图 1 是原始底图；参考图 2 是黑白视觉遮罩。白色区域对应允许修改的右手范围，黑色区域对应必须尽量保持的画面。

需要改变：让右手具有自然的五指数量、关节方向、长度比例、遮挡关系和受光，使手掌与手腕连接合理。

必须保持：脸、发型、身体、左手、服装、饰品、姿态、背景、构图、颜色、光线和遮罩外全部内容。不要改变人物身份，不要扩大编辑范围。

避免：多余手指、缺失手指、融合手指、手掌扭曲、饰品漂移、遮罩外重绘、随机文字和水印。
```

**观察点：** 除右手外的任何明显变化都应计入“不变量保持”扣分。

## 场景 6：准确替换图片文字

**验证重点：** 指定文字准确、可读，同时原海报布局和非目标文字保持稳定。

**参考图：** 1 张包含现有标题和日期的海报，标记为“其他”。请使用没有隐私信息、版权争议或真实品牌限制的测试海报。

**A 组提示词：**

```text
把海报标题改成“夏夜影像计划”，日期改成“2026.08.15 / 19:30”，保持原设计。
```

**B 组提示词：**

```text
编辑目标：只替换参考图 1 中的主标题和日期，保持原海报设计不变。

需要显示的准确文字：
主标题：“夏夜影像计划”
日期：“2026.08.15 / 19:30”

文字要求：逐字准确、清晰可读，不得改写、增删、翻译或生成拼音。主标题继续使用原标题的区域、层级、对齐方式和相近视觉重量；日期继续位于原日期区域。

必须保持：原画布比例、背景图像、人物或主体、颜色、材质、装饰、留白、版式网格，以及除主标题和日期以外的现有内容。不要重新设计整张海报。

避免：乱码、错别字、额外英文、伪造 logo、重复标题、随机小字、水印，以及改变非目标文字。
```

**观察点：** 本场景额外记录文字准确率：主标题和日期全部正确为 2 分，有一处小错为 1 分，无法正确阅读为 0 分。

## 后续效果验证标准

用户已明确选择先接入不改请求层的 G3-lite。以下标准继续用于判断六条配方是否值得长期保留、精简或调整：

- B 组在至少 4 个场景中比 A 组高 2 分或以上。
- B 组没有导致明显更严重的身份漂移、构图漂移或参考图混用。
- 至少 2 个改善场景属于日常确实会重复使用的任务，而不是只在测试中成立。
- 产品中只保留验证有效的少量配方，不导入完整图库。

如果未达到标准，则回退或调整对应模板；不能据此启动 G1、G2 或新的模板入口。
