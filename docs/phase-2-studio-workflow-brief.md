# 阶段 2：创作台小步调整

状态：阶段 2A、阶段 2B 均已实施并验证

更新：2026-07-13

## 1. 为什么撤回上一版

上一版把“降低低频功能干扰”推导成了较大范围的界面重排，包括移动提示词底栏、调整画布入口、收起模板和词组、重排桌面与手机结构。这超过了用户希望的小步改善范围，也没有清楚说明实际体验会如何递进。

用户明确不希望重构整个创作台。后续必须把每个变化拆成可以单独理解、确认、实施和验收的小批次。

## 2. 已澄清的产品要求

- 生成方式继续使用用户熟悉的“图生图”和“文生图”语义，不改成“开始改图”和“生成图片”。
- 词组、模板、保存模板、AI 优化和翻译目前已经是底栏图标，这种紧凑入口可以保留。
- “使用率低”不等于应该隐藏或删除；对词组和模板的诉求是以后改善实际能力和使用价值。
- 合影助手可以从主界面的大块表单中移出，改为底栏里的简略图标入口，但功能本身保留。
- 画布的问题是产品目标和工作流尚未定义，不是当前入口样式问题。在完成单独的产品规划前，不调整画布入口或界面权重。
- 当前三栏结构、底部提示词栏、结果区、近期资产、提示词预览和移动端整体顺序暂时不动，除非以后针对其中某一项单独说明并获得确认。

## 3. “阶段”在本项目里是什么意思

阶段不是“把一个页面整体重做一遍”，而是一个可以独立交付的检查点。每个阶段必须满足：

1. 只解决一个清楚的问题。
2. 实施前能用“原来怎样、改后怎样”说明白。
3. 不依赖顺手修改其他模块。
4. 有独立验收标准和回退边界。
5. 完成后暂停，下一项重新确认。

阶段名称只是管理工作范围，不能被理解成已经获得整批改造授权。

## 4. 重新拆分后的阶段 2

### 阶段 2A：生成按钮语义与状态

当前：底栏同时显示两个按钮。存在参考图时，“参考图生成”可用，“无参考图生成”显示“需移除参考图”；没有参考图时则相反。用户每次都会看到一个无法点击的按钮。

候选调整：按钮区域只保留一个位置，但沿用熟悉的业务术语：

- 有参考图时显示“图生图”。
- 没有参考图时显示“文生图”。
- 内部继续分别调用现有两个处理函数，不改变上游请求。
- 加载、禁用和错误状态分别延续图生图或文生图语义。

用户已选择方案 A：保留一个动态按钮，并沿用“图生图 / 文生图”名称。

保持不变：底栏位置与尺寸、输入框、全部图标、参数、参考图区域、结果区和请求逻辑。

### 阶段 2B：合影助手入口

当前：合影助手以完整表单常驻在左侧参考图区域下方，包括开关、动作、场景关系和补充提示词。

候选调整：

- 从左侧主界面移除完整表单。
- 在底栏工具图标区增加一个合影助手图标。
- 点击图标后打开现有合影设置面板，不删除任何选项。
- 条件不足时给出不可用状态；满足多人物参考条件后可设置并显示已启用状态。
- 不改变合影提示词的拼接方式和生成请求。

阶段 2B 必须在阶段 2A 完成后单独提供入口位置、打开方式、状态反馈和验收草图，再请求确认，不能因用户原则同意就直接实施。

## 5. 本阶段明确不做

- 不移动或取消固定底部提示词栏。
- 不隐藏词组、模板、保存模板、AI 优化和翻译图标。
- 不重排三栏结构或移动端整页顺序。
- 不调整画布入口、快速生成与画布的关系。
- 不修改提示词预览、近期资产或结果浏览方式。
- 不修改模型参数显示逻辑。
- 不修改 API 配置、供应商请求、历史存储或本地预设。

## 6. 后续阶段如何理解

以下只是待规划的问题清单，不代表获准实施：

- 结果与历史：解决主图、一次性结果流、刷新恢复和指定历史诊断之间的关系。
- 模型参数：针对不同上游逐个沉淀经过实际验证的参数能力，未知模型保留兜底。
- 词组与模板：先确认实际使用障碍，再决定搜索、组合、管理或复用能力如何改进。
- 画布与工具箱：先定义它们解决什么任务、输入是什么、输出去哪里，再决定界面和入口。

每一项都必须重新提供现状、目标、备选方案、保持不变、风险和验收标准，并获得明确确认。

## 7. 阶段 2A 实施结果

- 原来的两个互斥按钮已经合并为一个固定位置的动态按钮。
- 没有参考图时显示“文生图”，有参考图时显示“图生图”。
- 当前模式已有任务进行时，按钮显示“继续文生图”或“继续图生图”，仍允许沿用现有并行任务能力。
- 点击动态按钮后，文生图继续调用原 `handleTextToImageGenerate`，图生图继续调用原 `handleGenerate`。
- PC 端底栏继续固定在浏览器底部；输入框、工具图标、参数和底栏整体结构未移动。
- 为模式和状态文案增加纯函数测试，没有修改供应商请求和本地数据。

验证结果：

- `npm run check` 通过：6 个测试文件、36 项测试、类型检查和生产构建均成功。
- 在 1440×900 桌面视口中，从页面顶部滚动到 700px 后，底栏仍固定在视口底部，按钮位置不变。
- 无参考图状态只显示一个“文生图”按钮，旧的“参考图生成”“无参考图生成”“先传参考图”按钮均不存在。
- 浏览器控制台无警告或错误。
