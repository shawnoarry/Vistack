# Vistack

Vistack 是一个基于 Vue 3 和 TypeScript 的 AI 图像生成工作台。它通过可配置的 OpenAI 兼容接口和供应商专用接口，支持文生图、参考图再创作、本地历史记录、资产库、画布工作台和创作工具箱。

## 主要功能

- 文生图与参考图生成
- 自定义接口、模型、API 预设和本地代理
- 针对不同供应商的请求格式与图像尺寸兼容
- 本地生成历史与资产管理
- 包含原图的 ZIP 备份、内容预览与合并恢复
- 支持本地项目保存的画布工作台
- 图片反推提示词、自定义模特、一键换装和遮罩编辑等创作工具
- 自动隐藏凭据的诊断信息复制功能

浏览器数据保存在 `localStorage` 和 IndexedDB 中。API 凭据由用户在应用内填写，不应提交到仓库。

创作台和资产库对已单独保存的图片使用最长边 640 像素的缩略图。首次浏览时在本地生成缓存，预览、下载、作参考和备份仍使用原图。关闭预览或完成图片操作后释放历史列表持有的原图；正在预览、作参考或放入画布的图片会按需保留。旧版内嵌图片和未保存成功的远程图片保持原有方式。缩略图缓存不包含在备份中，恢复后会重新生成。

## 备份与恢复

在“资产库 → 备份与恢复”中下载 ZIP 备份，或选择备份文件预览后合并恢复。

- 包含生成记录、提示词、参数、原图、历史参考图、已保存的生图及提示词助手接口预设和收藏夹。
- 图片以原文件保存在 `images/` 中，不重新编码画质；相同内容只保存一份。`manifest.json` 保存记录及图片路径。
- 只有远程链接的图片会尝试下载。失败的图片会列为缺失项，并要求点击“下载不完整备份”；缺失图片无法从该备份恢复。
- API 密钥和代理密码默认不导出。选择包含时，ZIP 内的密钥为明文。恢复含密钥的备份时，也需要单独勾选恢复密钥。
- 恢复会校验图片内容，按记录和预设 ID 跳过已有项，不覆盖现有内容。图片与生成记录一起提交；接口预设或收藏夹保存失败时会单独报告，可重试导入。
- 当前不包含画布布局、工具箱独立资产、自定义模板词组和未完成任务。备份需要通过 localhost 或 HTTPS 访问应用。
- 当前上限为单份 ZIP 及解压内容 512 MB、单张图片 128 MB、10000 个图片文件。备份在浏览器内生成，不上传到云端；远程图片下载仍会访问其原地址或已配置的同源代理。

## 本地开发

环境要求：

- Node.js 18 或更高版本
- npm

```bash
npm install
npm run dev
```

开发服务器默认地址为 `http://localhost:3000`。

## 完整检查

```bash
npm run check
```

该命令会依次运行 Vue 与 Node TypeScript 检查、Vitest 测试和生产构建。

也可以单独运行：

```bash
npm run typecheck
npm run test
npm run build
npm run preview
```

## 项目结构

```text
api/             本地及部署环境使用的代理实现
docs/            当前项目记录与历史归档
src/components/  Vue 界面组件
src/services/    API 请求构建与供应商适配
src/types/       共用 TypeScript 类型
src/utils/       存储、诊断、端点和尺寸工具
```
